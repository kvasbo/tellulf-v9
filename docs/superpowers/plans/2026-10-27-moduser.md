# Modes Implementation Plan

> **For agentic workers:** Steps use checkbox (`- [ ]`) syntax for tracking. Tasks are in dependency order; each ends green (`go test ./...`, Biome) and is committable on its own.

**Goal:** Let MQTT switch the kiosk between pages ("modes"): the existing overview, a power page with everything Tibber knows, a calendar page with every detail, and a weather page. Each mode has its own URL, and the switch is a calm cross-document page transition.

**Architecture:** The server owns the mode. `internal/smarthouse` reads `tellulf/mode` and parses it with the new `internal/mode` package. The web server publishes the mode's path through the SSE hub like a fragment (sent on change, included in every snapshot) and never redirects; `client.js` navigates when it differs from the page's own path and the tab follows the mode (the page last opened by hand in the tab was `/`). Each page is a templ layout on a shared `shell`; its parts are SSE fragments as before, and `live.js` asks for only its own (`/sse?events=…`). All arithmetic for the charts (bar geometry, scales, ticks) happens in `internal/view`; templates only place SVG elements. `@view-transition { navigation: auto }` with named clock/date/temperature elements gives the transition.

**Tech Stack:** Go 1.27, templ (`go generate ./...`), plain ES modules in `public/`, Biome 2.5.15, Playwright Chromium for 1080p screenshots and the end-to-end check (it supports cross-document view transitions and `Temporal`).

**Spec:** `docs/superpowers/specs/2026-10-27-moduser-design.md` (screenshots next to it: `2026-10-27-strom.webp`, `2026-10-27-kalender.webp`, `2026-10-27-vaer.webp`).

## Global Constraints

- Same look as Natt: the colour tokens, Inter Tight 200/300/400, the type scale (12, 18, 22, 28, 35, 40, 48, 120, 280), 96 px side margins, 80 px top. Reuse the existing classes (`.label`, `.cell .value`, `.cell .detail`, `.now`, `.temp`, `.line1/2`, `.today-head`, `.ev`, `.note`, `.dot-*`) wherever it is the same thing. Accent only for "now"; blue only for precipitation.
- The page transition is the only motion and the only `@keyframes`; it runs only on navigation between modes. Fragment swaps stay instant; reloads never animate; `prefers-reduced-motion` turns it off.
- Norwegian number formatting through the helpers in `internal/view/format.go` (decimal comma, `−`, narrow no-break space before units).
- Missing data is absence: a row without data shows its label only; a chart without data shows no bars.
- Every new SSE fragment has exactly one `data-sse` element on its page.
- Never connect to the real MQTT broker or Tibber feeds while developing: the real kiosk holds Tibber's two websockets per token, and a mode message would switch the real screen. Use the Tibber demo token from the README and a local broker.

## Review Focus

1. Time keys: Tibber's times carry their own zone (`+01:00`); map lookups must use Unix time, not `time.Time`. Tests: `TestChartsMatchHoursAcrossZones`, `TestMergeHours`.
2. Live hour marks after a gap in the feed must not pile missed hours onto one. Test: `TestLiveHoursSkipsBoundaryAfterGap`.
3. Days with 23 or 25 hours: the hourly chart has one place per hour. Test: `TestTodayChartOnDSTDay`.
4. Navigation loop: the client compares the mode's path with `location.pathname` exactly; the server serves exactly `/`, `/strom`, `/kalender`, `/vaer`. Which tabs follow: the last page opened by hand decides; the mode's own navigations and reloads must not count as opened by hand.
5. The SSE filter must always let `version` and `mode` through for pages that list them (they are handler names in `live.js`).
